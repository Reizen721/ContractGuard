## 可复现命令

启动已配置 DeepSeek 的服务并登记演示项目后运行：

```powershell
pnpm acceptance:v18:deepseek --api-url http://127.0.0.1:18083 --output ..\my-v18-live-evidence
```

脚本会调用真实模型，因此不属于默认 `pnpm check`。输出目录必须是新目录。若客户端验证中断，先查看服务历史；可通过 `--resume-run <UUID>` 继续检查已有任务，避免重复付费提交。

验证脚本检查八组事项：服务与 MCP 就绪、LLM 必要动作、共享调用方历史、真实项目测试、模型证据引用、分页/导出/重新连接、固定流程对照、原始文件未改变。模型生成的说明仍需结合确定性证据人工审阅，引用编号合法不等于文字推论必然正确。
